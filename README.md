# Planora Cold Case — CASE 001: The Collapse

Static interactive investigation PWA-style website. Fictional case and AI-generated illustration assets.

## Deployment (GitHub Pages)
Upload `index.html`, `style.css`, `app.js` and the `assets` folder **to the root** of the repository. In Settings → Pages, select Deploy from a branch → main → /(root). Wait for GitHub Pages deployment, then hard refresh.

## Gameplay
Envelope 1 opens by default. Investigate evidence to discover access codes for the next envelopes, in order. Four envelopes, documents, scene images, five suspect dossiers, notes, timeline, evidence board and evidence-verification verdict. Progress stored locally in the browser.

This is an extended playable prototype, **not** a fully complete 6–9 hour commercial game. Final attribution is intentionally not fabricated without sufficient proof. A commercial release needs more substantial puzzles, editorial review, accessibility testing, and a server-side answer check if codes must not be exposed in public source code.

All photographs are fictional AI-generated illustrative crops; they are not actual forensic images. Some AI images originate from composite interface concept art and should be reviewed before commercial use.
